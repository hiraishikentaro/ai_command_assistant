# 自然言語入力受付機能（FR-001）詳細設計

## 1. 機能概要

自然言語入力受付機能は、AI Command Assistant (ACliA) の入り口となる部分で、ユーザーから自然言語形式でのコマンド指示を受け付け、システム内部で処理可能な形式に変換する機能です。

## 2. 機能要件

### 2.1 基本要件

- CLI パラメータとして指定された自然言語指示の受付
- 対話モード（引数なしで起動時）でのプロンプト表示と入力受付
- 入力テキストの前処理と正規化
- 複数言語（日本語/英語）の自動検出と適切な処理

### 2.2 入力モード

1. **コマンドライン引数モード**:

   - 形式: `acia "自然言語での指示"`
   - 1 回の実行で 1 つのコマンド生成を完結

2. **対話モード**:
   - 形式: `acia`（引数なし）で起動し、プロンプトを表示
   - ユーザーの入力を受け付け、結果表示後も終了せずに次の指示を待つ
   - 「exit」「quit」などの特定入力で終了

## 3. 技術仕様

### 3.1 入力処理フロー

```
[ユーザー入力] → [入力モード判定] → [前処理・正規化] → [言語検出] → [コア処理へ]
```

### 3.2 前処理・正規化

- 先頭・末尾の空白除去
- 複数の連続する空白の単一空白への正規化
- エスケープ処理（引用符、バックスラッシュなど）
- 句読点の正規化（必要に応じて）

### 3.3 言語検出

- 入力テキストの言語（日本語/英語）を自動検出
- 検出方法: 文字種の統計解析（漢字・ひらがな・カタカナの比率）
- 言語情報を内部状態として保持し、LLM プロンプト最適化に使用

### 3.4 データ構造

```rust
pub struct UserInput {
    pub raw_text: String,       // 元の入力テキスト
    pub normalized_text: String, // 正規化されたテキスト
    pub detected_language: Language, // 検出された言語
    pub input_mode: InputMode,  // 入力モード（CLI引数/対話）
    pub timestamp: DateTime<Utc>, // 入力タイムスタンプ
}

pub enum Language {
    Japanese,
    English,
    Other,
}

pub enum InputMode {
    CommandLine,
    Interactive,
}
```

### 3.5 エラーハンドリング

- 空の入力: 適切なメッセージを表示して再入力を促す
- 文字化けなど不正な入力: エラーメッセージを表示して正しい入力方法を説明
- 過度に長い入力: 警告と共に処理を続行するか確認

## 4. 実装方針

### 4.1 モジュール構成

```
src/
  ├── cli/
  │   ├── mod.rs             # モジュール定義
  │   ├── args.rs            # コマンドライン引数処理（clap利用）
  │   └── interactive.rs     # 対話モード処理
  └── input/
      ├── mod.rs             # モジュール定義
      ├── processor.rs       # 入力処理メインロジック
      ├── normalizer.rs      # テキスト正規化
      └── language_detector.rs # 言語検出
```

### 4.2 外部ライブラリ

- **clap**: コマンドライン引数のパース
- **rustyline**: 対話モードの入力処理（履歴機能、編集機能）
- **chrono**: タイムスタンプ処理

### 4.3 テスト戦略

- 単体テスト: 各前処理関数、言語検出機能のテスト
- 結合テスト: 入力から正規化までの一連のフローのテスト
- モックテスト: CLI と対話モードの入出力テスト

## 5. ユーザーインターフェース

### 5.1 コマンドライン引数

```
Usage: acia [OPTIONS] [INPUT]

Arguments:
  [INPUT]  自然言語でのコマンド指示（省略時は対話モードで起動）

Options:
  -e, --execute     生成されたコマンドを確認後に実行する
  -c, --copy        生成されたコマンドをクリップボードにコピーする
  -v, --verbose     詳細な説明を表示する
  -h, --help        ヘルプを表示する
  -V, --version     バージョン情報を表示する
```

### 5.2 対話モードプロンプト

```
ACliA v0.1.0
コマンドについて日本語で質問してください。終了するには 'exit' と入力してください。

>
```
