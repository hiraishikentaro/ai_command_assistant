# コマンド説明表示機能（FR-003）詳細設計

## 1. 機能概要

コマンド説明表示機能は、AI Command Assistant (ACliA) が生成したコマンドの詳細な説明を提供する機能です。ユーザーがコマンドの構造や目的、各オプションの意味を理解できるよう、わかりやすく整形された形式で情報を表示します。

## 2. 機能要件

### 2.1 基本要件

- 生成されたコマンドの全体的な目的と概要の表示
- コマンドを構成する主要部分の詳細説明
- 各オプションやフラグの意味と効果の説明
- 想定される実行結果の概要
- 関連するコマンドの提示

### 2.2 表示コンポーネント

1. **コマンド全文表示**:

   - 生成されたコマンド全体を強調表示

2. **目的説明**:

   - コマンドが実行する操作の目的を簡潔に説明

3. **オプション詳細**:

   - コマンドを構成する各部分の詳細説明
   - パイプやリダイレクトなどの接続部分の説明

4. **関連コマンド**:
   - 類似の目的を達成できる代替コマンド
   - より詳細な情報を得るためのヘルプコマンド

## 3. 技術仕様

### 3.1 表示フォーマット

```
COMMAND: <コマンド全文>

PURPOSE: <コマンドの目的説明>

OPTIONS:
  - <オプション1>: <説明1>
  - <オプション2>: <説明2>
  ...

RELATED: <関連コマンド1>, <関連コマンド2>, ...
```

### 3.2 表示スタイル

- コマンド全文: 太字またはハイライト表示
- 各セクション見出し: 大文字または色付き表示
- オプション部分: リスト形式でインデント表示
- 関連コマンド: カンマ区切りのリスト

### 3.3 データ構造

```rust
/// コマンド説明
pub struct CommandExplanation {
    /// コマンド全文
    pub command: String,
    /// コマンドの目的
    pub purpose: String,
    /// コマンドのオプション説明
    pub options: Vec<OptionExplanation>,
    /// 関連コマンド
    pub related_commands: Vec<String>,
}

/// オプション説明
pub struct OptionExplanation {
    /// オプション部分のテキスト
    pub option_text: String,
    /// 説明
    pub explanation: String,
}
```

### 3.4 表示処理フロー

```
[コマンド生成] → [説明データ構築] → [フォーマット適用] → [色付け/スタイル適用] → [ターミナル出力]
```

## 4. 実装方針

### 4.1 モジュール構成

```
src/
  ├── explanation/
  │   ├── mod.rs           # モジュール定義
  │   ├── formatter.rs     # 表示フォーマット処理
  │   ├── components.rs    # 説明コンポーネント
  │   └── styles.rs        # 表示スタイル
  └── display/
      ├── mod.rs           # モジュール定義
      └── terminal.rs      # ターミナル表示処理
```

### 4.2 外部ライブラリ

- **colored**: ターミナルでの色付き表示
- **textwrap**: 長いテキストの折り返し処理
- **unicode-width**: マルチバイト文字の適切な幅計算

### 4.3 テスト戦略

- 単体テスト: 説明データの構築、フォーマット処理
- 視覚的テスト: 異なるターミナル環境での表示テスト
- シナリオテスト: 様々な複雑なコマンドでの表示テスト

## 5. ユーザーエクスペリエンス

### 5.1 表示例

```
COMMAND: find . -name "*.txt" | xargs wc -l

PURPOSE: カレントディレクトリ以下のテキストファイルを検索し、各ファイルの行数を表示します

OPTIONS:
  - find . -name "*.txt": カレントディレクトリ(.)から.txt拡張子のファイルを検索
  - xargs wc -l: 検索結果の各ファイルに対してwc -lコマンド（行数カウント）を実行

RELATED: grep, ls, cat
```

### 5.2 ユーザー操作

- 説明表示後、ユーザーは以下の操作を選択可能:
  - コマンドのコピー
  - コマンドの実行
  - 詳細な説明の表示/非表示の切り替え
  - 関連コマンドの選択と説明表示

### 5.3 アクセシビリティ

- 色覚異常を考慮した色選択
- ターミナルの幅に応じた適切なテキスト折り返し
- ASCII アートや特殊文字に依存しない基本表示モード

## 6. 将来的な拡張案

### 6.1 インタラクティブな説明

- 説明の特定部分をクリックまたは選択して追加情報を表示
- コマンドの各部分にカーソルを合わせると詳細が表示されるホバー機能

### 6.2 例示と実行結果のプレビュー

- コマンドの典型的な実行例とその結果の表示
- 安全な場合は、実行結果のプレビュー生成

### 6.3 学習リソースの統合

- 特定コマンドに関する詳細な学習リソースへのリンク
- マニュアルページ (man) への直接アクセス機能

### 6.4 説明のカスタマイズ

- ユーザーの経験レベルに応じた説明の詳細度調整
- 好みの表示形式や色設定のカスタマイズ
